Is this a low-complexity agent task? Yes when what to do is fully specified (exact files and expected behavior, or a fixed list of commands to run and report) and tests or commands check the result. No when it needs security analysis, open-ended design or planning, research, diagnosis of an unknown cause, a review that must find unknown problems, or judgment across a large codebase.
